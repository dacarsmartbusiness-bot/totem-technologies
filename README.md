Este repositorio conserva artefactos versionables y revisados:

- Workflows n8n de TOTEM, sanitizados.

Los artefactos se preservan con su fecha y nombre de origen. Que un workflow figure en este repositorio no acredita por sí solo que esté activo o listo para producción; revisar su metadato `active`, fecha y clasificación operativa antes de promoverlo.
